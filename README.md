# Unique Visions Home Care LLC

Marketing website for **Unique Visions Home Care LLC**, a non-medical in-home care provider based in Hammond, Louisiana.

Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui. Brand details are drawn from the company’s public Facebook presence and NPI registry listing.

## Pages

- `/` — Home
- `/services` — Care services
- `/about` — Company story & service area
- `/contact` — Phone, email, office, and inquiry form

## Local development

```bash
npm install
npm run dev -- --port 4321
```

Open [http://127.0.0.1:4321](http://127.0.0.1:4321).

### Other scripts

```bash
npm run build
npm start -- --port 4321
npm run lint
```
